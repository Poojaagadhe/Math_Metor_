# Algebra Fundamentals

## Linear Equations

A linear equation is an equation of the form:
```
ax + b = 0
```

Where `a` and `b` are constants and `x` is the variable.

**Solution**: x = -b/a (provided a ≠ 0)

### Systems of Linear Equations

For two equations with two variables:
```
a₁x + b₁y = c₁
a₂x + b₂y = c₂
```

**Methods**:
1. **Substitution**: Solve one equation for one variable, substitute into the other
2. **Elimination**: Add/subtract equations to eliminate a variable
3. **Matrix method**: Use matrices and determinants

## Quadratic Equations

Standard form:
```
ax² + bx + c = 0
```

**Quadratic Formula**:
```
x = (-b ± √(b² - 4ac)) / (2a)
```

**Discriminant**: Δ = b² - 4ac
- If Δ > 0: Two distinct real roots
- If Δ = 0: One repeated real root
- If Δ < 0: Two complex conjugate roots

**Factoring**: If the quadratic can be factored as (x - p)(x - q) = 0, then x = p or x = q

## Polynomials

A polynomial of degree n:
```
P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀
```

**Key Properties**:
- Degree: Highest power of x
- Leading coefficient: Coefficient of highest degree term
- Roots/zeros: Values of x where P(x) = 0

**Factor Theorem**: If P(a) = 0, then (x - a) is a factor of P(x)

**Remainder Theorem**: When P(x) is divided by (x - a), the remainder is P(a)

## Inequalities

**Linear Inequalities**: ax + b < 0 (or >, ≤, ≥)
- Solve like equations, but reverse inequality when multiplying/dividing by negative

**Quadratic Inequalities**: ax² + bx + c < 0
1. Find roots of ax² + bx + c = 0
2. Test intervals between roots
3. Determine where inequality holds

## Common Mistakes

1. **Sign errors**: Forgetting to flip inequality when multiplying/dividing by negative
2. **Discriminant**: Miscalculating b² - 4ac
3. **Factoring**: Missing common factors before applying formulas
4. **Domain restrictions**: Dividing by expressions that could be zero
