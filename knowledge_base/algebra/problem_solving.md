# Problem-Solving Strategies

## General Approach

1. **Understand the Problem**
   - Read carefully
   - Identify what is given
   - Identify what needs to be found
   - Draw diagrams if helpful

2. **Plan the Solution**
   - Identify the topic/concept
   - Recall relevant formulas
   - Consider similar problems solved before
   - Break complex problems into steps

3. **Execute the Plan**
   - Work step-by-step
   - Show all work clearly
   - Check units and dimensions
   - Verify intermediate results

4. **Verify the Answer**
   - Does it make sense?
   - Check units
   - Substitute back into original problem
   - Consider edge cases

## Common Problem-Solving Techniques

### Working Backwards
Start from the desired result and work backwards to the given information.

### Substitution
Replace complex expressions with simpler variables.

### Pattern Recognition
Look for patterns in numbers, expressions, or sequences.

### Dimensional Analysis
Check that units are consistent throughout the solution.

### Special Cases
Test with simple values (0, 1, -1) to verify formulas.

## Checking Your Work

**Algebra**:
- Substitute answer back into original equation
- Check for extraneous solutions
- Verify domain restrictions

**Calculus**:
- Check critical points are actually in the domain
- Verify endpoints are considered
- Ensure derivative/integral formulas applied correctly

**Probability**:
- Check that probabilities sum to 1 (when appropriate)
- Verify 0 ≤ P ≤ 1 for all probabilities
- Ensure sample space is correctly identified

**Linear Algebra**:
- Verify matrix dimensions are compatible
- Check determinant calculations
- Confirm inverse by multiplying AA⁻¹

## Red Flags

Watch out for these common issues:
- Division by zero
- Square root of negative numbers (in real numbers)
- Logarithm of non-positive numbers
- Undefined trigonometric values
- Probability > 1 or < 0
- Forgetting absolute value signs
- Sign errors in formulas
